# Python vs JavaScript Cheatsheet

A chronological reference guide comparing syntax and features as we learn them day by day.

## Day 01: Hello World, Functions, & Data Structures

| Feature                      | JavaScript (Node.js)               | Python                                     |
| :--------------------------- | :--------------------------------- | :----------------------------------------- |
| **Print to Console**         | `console.log("Hello!")`            | `print("Hello!")`                          |
| **Command to Run**           | `node filename.js`                 | `py filename.py` (or `python filename.py`) |
| **File Extension**           | `.js`                              | `.py`                                      |
| **Line Endings**             | Optional semicolon `;`             | No semicolons                              |
| **Variables (Arrays/Lists)** | `let tasks = []`                   | `tasks = []`                               |
| **Adding to Array/List**     | `tasks.push(task)`                 | `tasks.append(task)`                       |
| **Functions**                | `function addTask(title) { ... }`  | `def add_task(title): ...`                 |
| **Objects / Dictionaries**   | `{ title: "task", done: false }`   | `{"title": "task", "done": False}`         |
| **Booleans**                 | `true` / `false`                   | `True` / `False`                           |
