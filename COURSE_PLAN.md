# 8-Week Job-Ready Course Plan — Lane A (Python & AI-App Engineer)

**Goal:** Land a Junior Python / Backend / AI-App Engineer role in **8 weeks (~150–190 focused hours, 3–4 hrs/day, 6 days/week)**.  
**Strategy:** **80% Python, Backend, Databases & AI Engineering** + **20% Clean UI** (using modern templates/components so your AI apps look polished without losing weeks to CSS).

---

## Daily 3-Hour Block
1. **20 min** — Spaced-repetition warm-up / `"quiz me"`
2. **60 min** — Today's concept + daily quest (`assert` / `pytest`)
3. **80 min** — Build toward the current Boss Project (from Week 2 onward)
4. **20 min** — `"finish today"` (update `README.md` XP/Log, commit, push to GitHub)

---

## Weekly Sprint Breakdown

### **Weeks 1–2: Python Developer & Engineering Core**
- **Week 1 (Days 11–16):**
  - Day 11: Sets & set operations
  - Day 12: Tuples & string manipulation
  - Day 13: List & dictionary comprehensions
  - Day 14: Modules, packages, `venv`, `pip`
  - Day 15: File handling (`TXT`, `CSV`, `JSON`)
  - Day 16: Object-Oriented Programming (classes, `__init__`, dataclasses)
- **Week 2 (Days 17–22):**
  - Day 17: Clean code & project structure
  - Day 18: Unit testing with `pytest`
  - Day 19–20: SQL fundamentals & relational DB design (`SELECT`, `JOIN`, CRUD)
  - **Days 21–22 (Boss 1):** **Personal Expense / Data Tracker** (SQLite + `pytest` test suite)

### **Week 3: Backend APIs & Databases**
- **Days 23–25:** HTTP/REST, **FastAPI**, Pydantic validation, error handling
- **Days 26–27:** Connecting FastAPI to **PostgreSQL** + JWT Authentication
- **Day 28 (Boss 2):** **Production-Style FastAPI + Postgres API** (with `pytest` `TestClient` tests)

### **Week 4: Data & ML Foundations**
- **Days 29–31:** **NumPy & pandas** essentials (arrays, DataFrames, data cleaning)
- **Days 32–34:** Core ML concepts (supervised vs unsupervised, train/test split, overfitting, evaluation metrics, embeddings & cosine similarity)

### **Weeks 5–6: AI Engineering, Clean UI & Cloud Deployment**
- **Week 5 (Days 35–40):**
  - LLM APIs, structured JSON outputs, prompt engineering
  - Vector Databases + **RAG** (chunking, indexing, retrieval, grounded answers)
- **Week 6 (Days 41–46):**
  - Tool calling, **AI Agents**, and **AI Evaluation** (accuracy/latency/cost)
  - **Docker** (`Dockerfile`, `docker-compose`) + Cloud Deployment + **Clean UI** (Streamlit or minimal web UI)
  - **Days 45–46 (Boss 3 — Flagship):** **Deployed AI/RAG Web App** (live URL + architecture diagram in README)

### **Weeks 7–8: DSA Essentials, System Design & Job Sprint**
- **Week 7 (Days 47–52):**
  - Pythonic DSA (arrays, dicts, sets, two pointers, sliding window, recursion/BFS) — 2 problems/day
  - AI & Backend System Design basics (caching, queues, DB indexing)
  - Portfolio, GitHub READMEs & resume polish
- **Week 8 (Days 53–58+):**
  - Mock technical + behavioral interviews
  - **5–10 targeted job applications/day** (Junior AI Engineer, Python Developer, Junior Backend/AI-App Engineer)
